# Legal

This repository has **no standard open-source licence**. The original author never published one, and nobody else can add one on his behalf. The author's own statements below are the terms.

## What the author, Jens Hassler, allowed

**Distribution** (manual, `doc/gfdoceng.txt`, section 8, and the "Legal stuff" section of gravity-force.de):

> Gravity Force is Freeware without any restrictions. You can distribute the program freely, as long you do it for free. To avoid downloads of old versions it's always good to include a link to this web page which is always actualized.

**Modification** (`doc/source.txt`, in the source archive he published):

> I won't encourage anyone to use this code in his/her own projects, but if you're willing to do this, you're welcome.
>
> And if you take the whole code to make a new and better Gravity Force out of it, I'd be very happy to host this version on the GF website.

**Linux builds** (the download page, `gfdown.htm`):

> BTW: It's possible to build a linux version out of this source. If you try and want to contribute a binary, please mail me.

The one condition is that this work must be distributed free of charge. It must not be sold.

Original homepage, archived: <https://web.archive.org/web/2018/http://www.gravity-force.de/>

## Third-party material

"GRAVITY FORCE" is the name of an Amiga game, Copyright (c) 1989 Kingsoft.

The original author's credits page says this remake contains no graphics or code from that game. It does contain:

- some of its sound effects, in `dat/gfsnd.dat`;
- a port of its title tune, in `dat/gf.xm`.

The original author could not license that material, so it is included here as it was in his freeware release. If you hold rights to anything in this repository and want it removed, open an issue and it will be taken down.
